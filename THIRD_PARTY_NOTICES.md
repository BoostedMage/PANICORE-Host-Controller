# Third-party dependencies and notices

This project publishes original Lua and PowerShell source code and command scripts. It does **not** contain PANICORE's executable, game assets, Unreal Engine packages, UE4SS binaries, or Microsoft runtime binaries.

- **UE4SS / RE-UE4SS**: game modding framework by the [UE4SS-RE project](https://github.com/UE4SS-RE/RE-UE4SS). The launcher downloads a pinned upstream ZIP (with SHA-256 verification). Upstream licenses and notices govern this dependency.
- **Microsoft Visual C++ Redistributable**: the launcher may offer to install the official Microsoft-signed runtime from Microsoft's download endpoint if it is missing. Microsoft licenses govern that runtime.
- **PANICORE**: proprietary third-party game. This mod is unofficial and unaffiliated; no proprietary game files are redistributed.

Do not upload downloaded dependency runtimes, PANICORE game files, player logs or saved games as part of future release source archives.
